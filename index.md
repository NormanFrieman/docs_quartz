# Bem-vindo ao Norman's Mind

Este é o meu digital garden — um espaço onde compartilho notas, ideias e conhecimentos sobre diversos temas.

## Sobre

Este site é gerado automaticamente a partir do meu vault do Obsidian usando [Quartz](https://quartz.jzhao.xyz).

## Navegação

- Use a **barra de pesquisa** no topo para encontrar notas específicas
- Explore o **grafo de conhecimento** no lado direito das páginas
- Navegue pelas **pastas** usando o explorador no lado esquerdo
